# 课后追单与活动复盘

## 步骤 9：课后总结与追单

按顺序输出：

1. 结束感谢：感谢参与，概括一个核心收获，给回看或后续入口。
2. 内容复盘：提炼 3–5 个关键点，帮助用户确认学到了什么。
3. 收获引导：邀请用户用一句话反馈，不诱导夸赞。
4. 私聊开场：结合真实参与行为询问感受和需求。
5. 未报名追单：先了解原因，再决定是否继续介绍。
6. 价格犹豫：提供判断框架，不承诺回本或贬低顾虑。
7. 沉默追单：最多进行克制的提醒，给明确退出空间。
8. 最终成交：说明真实截止、适配条件和入口；截止后停止沿用旧优惠。

不默认用户看过直播、领取过资料或表达过兴趣。只有上下文明确时才引用这些行为。

## 追单分流

| 用户状态 | 下一步 |
|---|---|
| 明确想参加 | 解决支付、时间或流程问题 |
| 有兴趣但不确定 | 找出一个主要顾虑并回答 |
| 暂时不适合 | 给可执行的小建议，结束追单 |
| 明确拒绝 | 尊重选择，不继续营销 |
| 长期沉默 | 一次简短收口，不制造紧迫感 |

## 步骤 10：活动复盘建议

输出五部分：

1. 数据复盘：朋友圈互动、私信回复率、进群率、到课率、社群互动率、成交率、课后转化率。
2. 重点私聊：按高意向、待判断、不适配分类，不输出个人敏感信息。
3. 二次转化：回放、资料、咨询或下一场活动的真实路径。
4. 下一场优化：找到流失最大的环节，定位对应文案或运营动作。
5. 后续朋友圈运营：价值内容、案例复盘、产品认知和日常信任的平衡。

## 迭代机制

将漏斗按阶段记录：触达 → 回复 → 进群 → 到课 → 互动 → 咨询 → 支付 → 课后成交。先定位转化下降最大的相邻环节，再提出恰好 3 个可测试优化方向；每次只改变一个主要变量，便于判断原因。

数据不完整时，明确哪些指标缺失，不自行估算。复盘关注决策，不追求漂亮数字。

## 输出检查

- 追单是否尊重拒绝和沉默？
- 优惠截止后是否停止继续使用旧口径？
- 复盘建议是否对应实际数据，而非泛泛而谈？
- 下一轮测试是否能观察到明确结果？
