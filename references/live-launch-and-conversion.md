# 直播发售与成交转化

## 直播现场内容

直播前后的文案与社群动作要衔接：提醒进入 → 强调正在讲什么 → 提炼阶段价值 → 发布产品 → 解释适配度 → 回答异议 → 明确真实截止时间。

对分钟级流程，使用表格输出：`时间｜角色｜话术／动作｜内容形式｜目标`。没有准确时间时，用相对时间，例如“开播后 20 分钟”，不要自行填写钟点。

## 步骤 8：成交转化

输出以下六类内容：

1. 成交提醒：说明产品已开放、适合谁、如何了解或报名。
2. 成交接龙：只记录真实报名或真实意向，不制造从众数据。
3. 福利限时：写清福利内容、截止时刻、适用条件与领取方式。
4. 名额紧迫：只有用户确认存在真实容量限制时使用，并说明口径。
5. 价格对比：比较同一产品真实价格、权益或成本，不虚构原价和市场价。
6. 最后一波：复述适合条件、真实截止时间和行动入口，允许用户理性退出。

## 成交逻辑

按“问题 → 代价 → 方案 → 证据 → 交付 → 适配 → 价格 → 风险解除 → 行动”组织。不是每条都要写全；选择与当前节点最相关的部分。

### 高客单产品

以诊断和适配为先。私聊先了解业务阶段、目标、执行时间与主要顾虑，再给出判断。不得用羞辱、恐惧或关系压力逼单。

### 免费或低客单产品

减少复杂解释，明确得到什么、如何参加、何时开始。仍要说明适合边界和真实条件。

## 常见异议

| 异议 | 回应重点 |
|---|---|
| 价格 | 先承认决策成本，再比较交付与当前问题成本，不承诺回本 |
| 时间 | 说明真实投入和节奏，帮助判断是否具备执行条件 |
| 效果 | 解释影响效果的条件，提供过程证据，不保证结果 |
| 不信任 | 给可核实资料、试学或咨询路径，不编造见证 |
| 再考虑 | 询问仍未确认的一个关键点，尊重截止后的选择 |

## 行动指令

根据场景只选一个主要动作：回复“报名”／“参加”、私信关键词、扫码预约、进入直播间、查看报名页或完成支付。`名额有限`、`错过不补`只能在事实成立且用户确认时使用。

## 输出检查

- 价格、优惠、名额和截止时间是否全部有用户依据？
- 产品交付是否具体，适合与不适合人群是否清楚？
- 是否避免收益保证和未经授权的成交截图？
- 私聊是否先判断适配，而不是连续施压？
