# 活动定位与邀请

## 步骤 1：活动定位

输出以下七项，并确保它们表达同一个价值主张：

1. 一句话定位：目标人群＋核心问题＋活动带来的具体改变。
2. 核心卖点：3–5 条，分别说明内容、方法、体验或资源上的差异。
3. 主标题：短、具体、能让目标人群认出自己。
4. 副标题：补充活动形式、核心收益或差异点。
5. 适合人群：用可识别的现状描述，不用空泛身份标签。
6. 参加理由：从痛点、收益、机会成本与行动门槛解释。
7. 钉子句：一句能在后续文案中反复出现的核心表达。

定位不是收益保证。避免“彻底改变”“保证成交”“人人都能”等绝对表达。

## 步骤 2：五类邀请函

### 朋友圈邀请

采用“真实场景或观察 → 目标人群的卡点 → 活动价值 → 时间与形式 → 单一行动”的结构。适合公开传播，避免像群发广告。

### 私信邀请

采用“关系或来意 → 为什么想到对方 → 适配点 → 低压力询问”的结构。熟人可引用真实交流背景；半熟关系先征得同意，不假装熟悉。

### 社群邀请

先说明对群成员的相关性，再列活动收益与时间，最后给统一回复关键词。避免连续刷屏。

### 裂变福利邀请

说明福利内容、真实价值、领取条件、截止时间和操作步骤。不得隐藏附加条件，不用虚构抢领人数。

### 入群福利邀请

说明入群即可获得什么、如何领取、何时失效以及群内后续安排。福利本身必须与活动主题相关。

## 判断规则

| 条件 | 写法调整 |
|---|---|
| 免费活动 | 降低参与门槛，重点提升预约和到课，不贬低免费内容 |
| 付费活动 | 清楚说明价格、交付、适合与不适合人群，避免只谈稀缺 |
| 熟关系 | 使用真实共同经历或对方已表达的需求 |
| 冷或半熟关系 | 先说明来意并给对方拒绝空间，不连续追问 |
| 高客单 | 先诊断适配度，再给方案与决策依据 |
| 低客单 | 缩短决策链，突出具体收益、领取步骤和期限 |

## 输出检查

- 标题和正文是否来自用户给出的事实？
- 五类邀请是否真正适配不同渠道，而非同文复制？
- 每类是否只有一个主要行动指令？
- 是否给不适合的人留下合理退出空间？
